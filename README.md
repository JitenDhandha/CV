# CV — Jiten Dhandha
This is my version-controlled CV, written in LaTeX. The format is adapted from [Harry Bevins's CV](https://github.com/htjb/CV). There's an additional custom Python script that automatically generates the LaTeX code for the Publications section. Previously, it was generated from a manually updated BibTeX file (using the `pybtex` package). It has now been upgraded to automatically querying a [public NASA ADS library](https://ui.adsabs.harvard.edu/public-libraries/-9hd8iXUQl6bWu8xYksd5A) (using the `ads` package) that I maintain every Monday at 9AM UTC (using GitHub Actions).
