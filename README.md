# CV — Jiten Dhandha
This is my version-controlled CV, written in LaTeX. The format is adapted from [Harry Bevins's CV](https://github.com/htjb/CV). There's an additional custom Python script that automatically generates the LaTeX code for the Publications section. Previously, it was generated from a BibTeX file (using the `pybtex` package) that needs to be manually updated. It has now been switched to querying a NASA ADS public library (using the `ads` package): [-9hd8iXUQl6bWu8xYksd5A](https://ui.adsabs.harvard.edu/public-libraries/-9hd8iXUQl6bWu8xYksd5A). This way, I can just add papers to the library and run the script to update the CV.
